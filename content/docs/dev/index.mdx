LPM's development surface. The marquee command is [`lpm dev`](/docs/dev/dev) — one command that picks up your Node version, syncs deps, loads `.env`, optionally serves over HTTPS, optionally exposes a public tunnel, and orchestrates multi-service projects. The rest of this section is the supporting cast: a parallel + cached task runner, runners for test / bench / lint / fmt / type-check, and the runtime + env management around it.

For a step-by-step walkthrough, see [Zero-config dev server](/docs/guides/zero-config-dev-server).
