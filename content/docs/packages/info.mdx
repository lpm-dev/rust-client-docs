---
title: lpm info
description: "Show metadata for a package — versions, dependencies, integrity, ecosystem."
---

```bash
lpm info <package> [--version <V>]
```

Fetches an `@lpm.dev/*` package's metadata and prints it in a human-readable card: name, description, the chosen version's ecosystem, integrity hash, and full dependency list. With `--json`, returns the raw metadata for tooling.

**Scope: `@lpm.dev/*` packages only.** Names without a scope+dot (`react`, `zod`, `lodash`) are rejected at parse time. For npm-registry metadata, use `npm view <pkg>` or hit the npm metadata API directly.

By default, `lpm info` shows the latest version. Pass `--version <V>` to inspect a specific release.

## Examples

```bash
lpm info @lpm.dev/owner.pkg                          # latest version
lpm info @lpm.dev/owner.pkg --version 2.1.0          # specific version
lpm info owner.pkg                                   # short form — same as @lpm.dev/owner.pkg
lpm info @lpm.dev/owner.pkg --json | jq '.versions' # structured output for tooling
```

## What's shown

For the chosen version:

- `version` — the actual semver
- `ecosystem` — `js`, `swift`, etc.
- `integrity` — SRI hash (truncated for display, full in `--json`)
- `dependencies` — declared runtime deps with their ranges

The full registry payload (every version, dist-tags, maintainers, README, etc.) is available via `--json`.

## Flags

| Flag | Effect |
| --- | --- |
| `--version <V>` | Show a specific version instead of latest |

Plus the [global flags](/docs/commands#global-flags) — `--json` returns the full registry record.
