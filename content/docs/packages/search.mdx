---
title: lpm search
description: "Search the registry for packages by name and description."
---

```bash
lpm search <query> [--limit <N>]
```

Returns up to 20 `@lpm.dev/*` packages whose name or description matches the query, ranked by relevance. Hits the lpm.dev registry directly — no local index, always fresh.

**Scope: lpm.dev only.** `lpm search` does not query npmjs.org or any `.npmrc`-declared registry. For npm-package discovery, use `npm search` or the npmjs.com web UI.

## Examples

```bash
lpm search highlight                # default: up to 20 hits
lpm search highlight --limit 5      # cap at 5
lpm search "react hooks" --json     # structured output
```

## Flags

| Flag | Effect |
| --- | --- |
| `--limit <N>` | Maximum results to return (1–20, default `20`) |

Plus the [global flags](/docs/commands#global-flags) — `--json` is useful for piping into other tools.
