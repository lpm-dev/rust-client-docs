---
title: lpm outdated
description: "List dependencies with newer versions available."
---

```bash
lpm outdated
```

Compares every entry in `package.json > dependencies` against the registry and prints the ones with newer versions available. Read-only — never modifies anything.

**Only `dependencies` is checked.** Entries in `devDependencies` are not surveyed.

## Example output

```text
Package           Current   Latest
react             18.2.0    19.0.0
zod               4.3.5     4.3.6
typescript        5.4.0     5.6.2
```

A row appears when the installed version (from `lpm.lock`) differs from the registry's latest tag.

## Ecosystem scope

By default, `lpm outdated` checks both `@lpm.dev/*` and npm-registry packages.

```bash
lpm outdated                     # both ecosystems (default)
lpm outdated --registry-only=lpm # @lpm.dev only — useful when npm is rate-limiting or offline
```

`--registry-only=all` is the explicit form of the default.

## Acting on the report

For `@lpm.dev/*` packages, [`lpm upgrade`](/docs/packages/upgrade) applies the updates (interactive at TTY, batch in CI). It's `@lpm.dev`-only today.

For npm packages, bump them per-package with `lpm install`:

```bash
lpm install zod@latest
lpm install react@^19            # explicit range
```

## JSON output

```bash
lpm outdated --json
```

Emits an envelope with `success`, `count`, `outdated_count`, and a `packages[]` array. Each row carries:

| Field | Meaning |
| --- | --- |
| `name` | Package name |
| `current` | Version resolved in `lpm.lock`, or `"?"` if the lockfile is missing |
| `wanted` | The **raw range string** from `package.json` (e.g., `"^4.3.0"`) — not a resolved version |
| `latest` | The newest version on the registry, regardless of range |
| `outdated` | `true` when `current` differs from `latest` |

## Flags

| Flag | Effect |
| --- | --- |
| `--registry-only <all\|lpm>` | Limit checks to a single ecosystem (default: `all`) |

Plus the [global flags](/docs/commands#global-flags) — `--json` is especially useful for scripting.
